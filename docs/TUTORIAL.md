# 轻舟 Skiff 使用教程

## 一、安装

### Linux（Ubuntu/Debian）

```bash
# 1. 下载并解压
tar xzf skiff-linux-x64.tar.gz

# 2. 进入目录
cd bundle

# 3. 运行（三种方式任选）

# 方式一：后台运行（推荐，不占终端）
./skiff.sh

# 方式二：直接运行（会占用终端）
./skiff

# 方式三：命令行后台运行
nohup ./skiff > /dev/null 2>&1 &
```

> 💡 **推荐使用 `skiff.sh`**，它会自动后台运行，关闭终端后程序继续运行。

### 创建桌面快捷方式（可选）

```bash
# 复制 desktop 文件到桌面
cp skiff.desktop ~/桌面/
# 或复制到应用菜单
cp skiff.desktop ~/.local/share/applications/

# 如果桌面上无法双击运行，需要设置为可信任
chmod +x ~/桌面/skiff.desktop
# 右键 → 允许启动 / Allow Launching
```

### 从源码构建

```bash
# 安装依赖
sudo apt install cmake ninja-build libgtk-3-dev libxtst-dev libxi-dev clang

# 克隆并构建
git clone <repo-url> skiff
cd skiff
flutter pub get
flutter build linux --release

# 运行
build/linux/x64/release/bundle/skiff
```

## 二、基本使用

### 启动后

启动后你会看到：
1. **屏幕右下角**出现一个半透明的悬浮按钮（50×110 像素）
2. **系统托盘**出现一个 "Skiff" 图标

### 悬浮按钮

```
┌─────────┐
│    ▲    │  ← 点击向上滚动
├─────────┤
│   ≡     │  ← 按住拖动，移动按钮位置
├─────────┤
│    ▼    │  ← 点击向下滚动
└─────────┘
```

**使用方法：**
1. 打开一个有滚动条的窗口（浏览器、文本编辑器等）
2. 点击悬浮按钮的 **▲** — 窗口向上滚动
3. 点击悬浮按钮的 **▼** — 窗口向下滚动
4. 按住中间的 **≡** 拖动 — 可以把按钮移到屏幕任意位置

### 找回悬浮按钮

如果悬浮按钮被藏到屏幕边缘、被隐藏，或一时找不到位置：

1. 在任意位置 **按住鼠标右键 2 秒**
2. 悬浮按钮会自动移动到鼠标当前位置附近

这个功能不依赖“启用中键手势”开关，关闭中键手势后仍然可用。

### 中键手势

**使用方法：**
1. 在任意窗口中，**按住鼠标中键**（滚轮键）
2. **移动鼠标**超过 20 像素
3. **松开中键** — 窗口会朝移动方向滚动一次

| 手势方向 | 滚动效果 |
|---------|---------|
| 向上移动 | 向上滚动 |
| 向下移动 | 向下滚动 |
| 向左移动 | 向左滚动 |
| 向右移动 | 向右滚动 |

## 三、托盘菜单设置

**右键点击**系统托盘的 Skiff 图标，弹出设置菜单：

```
┌─────────────────────────┐
│  显示/隐藏按钮           │  ← 切换悬浮按钮的显示/隐藏
│  ☑ 启用中键手势          │  ← 切换中键手势功能
│  ☐ 中键拖动反向          │  ← 反转中键手势的滚动方向
│─────────────────────────│
│  滚动行数 →              │  ← 选择每次滚动几行
│  ☐ 开机自启              │  ← 切换开机自动启动
│─────────────────────────│
│  退出                    │  ← 关闭程序
└─────────────────────────┘
```

### 显示/隐藏按钮
- 点击后悬浮按钮会在显示/隐藏之间切换
- 设置会自动保存，下次启动记住状态

### 启用中键手势
- **☑** 表示已启用，按住中键移动可触发滚动
- **☐** 表示已禁用，中键恢复原生功能（如浏览器中键点击打开新标签）
- 如果某些软件的中键功能与手势冲突，可关闭此选项

### 中键拖动反向
- **☑** 表示反向，向上拖会向下滚动，向左拖会向右滚动
- **☐** 表示正常方向，拖动方向与滚动方向一致

### 滚动行数
- 子菜单可选择 1-10 行
- 默认每次滚动 3 行
- 数值越大，一次滚动的距离越远

### 开机自启
- **☑** 表示已启用，系统登录时自动启动 Skiff
- **☐** 表示已禁用
- Linux 实现方式：在 `~/.config/autostart/` 创建 `skiff.desktop` 文件
- Ubuntu 上如果没有生效，请确认：
  - 已在托盘菜单勾选“开机自启”
  - `~/.config/autostart/skiff.desktop` 已生成
  - 文件里的 `Exec=` 是当前 Skiff 可执行文件的绝对路径
  - 如果移动过 Skiff 安装目录，请取消勾选后重新勾选一次

## 五、常见问题

### Q: 悬浮按钮没有出现在屏幕上？
**A:** 可以在任意位置按住鼠标右键 2 秒，Skiff 会把悬浮按钮移动到鼠标当前位置附近。也可以右键点击托盘图标 → 显示/隐藏按钮，确保按钮处于显示状态。

### Q: 点击悬浮按钮没有滚动效果？
**A:** 确保目标窗口（如浏览器）在悬浮按钮的**下方**。悬浮按钮使用 X11 Input Shape 技术让点击穿透到下层窗口。

### Q: 中键手势在某个软件中不工作？
**A:** 某些软件（如 Blender、Figma）会拦截中键事件。可以在托盘菜单中关闭"启用中键手势"，仅使用悬浮按钮。

### Q: 如何开机自启？
**A:** 右键点击托盘图标 → 开机自启（勾选）。Linux 会在 `~/.config/autostart/skiff.desktop` 创建自启动文件。

如果 Ubuntu 仍未启动，可手动检查：
```bash
cat ~/.config/autostart/skiff.desktop
```

确认 `Exec=` 后面的路径存在，并且可以在终端直接运行。Skiff 的 Linux 功能依赖 X11；如果 Ubuntu 登录的是 Wayland 会话，程序即使启动也可能无法正常滚动/监听中键，请在登录界面选择“Ubuntu on Xorg”。

### Q: 支持 Wayland 吗？
**A:** 目前不支持。Skiff 依赖 X11 的 XTest 和 XQueryPointer API，Wayland 下这些 API 不可用。请使用 X11 会话。

### Q: 如何修改滚动行数？
**A:** 右键点击托盘图标 → 滚动行数 → 选择 1-10。

## 六、技术原理

### 滚轮模拟
使用 XTest 扩展的 `XTestFakeButtonEvent` 注入系统级滚轮事件，目标应用收到的是**真实滚轮信号**，与物理鼠标滚轮完全相同。

### 中键手势
独立线程每 10ms 通过 `XQueryPointer` 检测鼠标中键状态。当中键按下且移动距离超过 20px 时触发滚动。

### 悬浮窗穿透
使用 X11 Input Shape 将悬浮窗的输入区域设为空，鼠标事件自动穿透到下层窗口。发送滚轮事件后立即恢复输入区域。

### 原生拖拽
使用 GTK 的 `gtk_window_begin_move_drag` 实现窗口拖拽，避免 MethodChannel 延迟，拖拽流畅无卡顿。
